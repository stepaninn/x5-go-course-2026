# Практика занятия 8

Откройте эту папку отдельно в IDE. Команды выполняются здесь, рядом с go.mod.

```bash
go mod download
go run .
```

Во втором терминале:

```bash
curl -i http://127.0.0.1:8080/health
```

До реализации обработчиков сервер отвечает **501 Not Implemented**. Тест `go test ./...` сначала намеренно красный: он ожидает готовый /health. После реализации всех требований тесты должны проходить. Одного готового TestHealth недостаточно для проверки всей практики, добавьте свои случаи.

Условие занятия находится в TASKS.md, домашняя работа в HOMEWORK.md. Хранилище в memory.go уже готово. После перезапуска данные исчезают. Перед запуском остановите другой учебный сервер на порту 8080.
