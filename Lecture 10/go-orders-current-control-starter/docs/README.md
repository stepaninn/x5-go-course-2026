# Swagger

Сгенерированные файлы Swagger должны появиться в этой директории.

Необходимо:

1. Добавить swaggo-аннотации к точке входа и каждому обязательному обработчику.
2. Выполнить `swag init -g cmd/api/main.go -o docs`.
3. Подключить Swagger UI к HTTP-серверу.

Сгенерированные файлы исключены из стартового шаблона через `.gitignore`. При сдаче студент должен удалить соответствующие строки из `.gitignore` либо принудительно добавить документацию в Git.
