# Домашняя работа — Unit Testing в Go

В пакете `homework/discount` находится небольшой сервис расчёта скидки.

Вам необходимо **написать unit-тесты** для всех экспортируемых функций пакета.

## Что нужно сделать

1. Создать `homework/discount/service_test.go`.
2. Покрыть тестами `Apply`, `ValidatePercent` и `FinalPrice`.
3. Для нескольких сценариев использовать **table-driven tests**.
4. Каждый сценарий таблицы запускать через `t.Run`.
5. Для проверок использовать `testify/assert` или `testify/require`.
6. Добавить `t.Parallel()` только там, где тесты действительно независимы.
7. Проверить ошибочные и граничные сценарии.
8. Добиться покрытия пакета `homework/discount` **не менее 80%**.

## Обязательные сценарии

### ValidatePercent

- `0` — допустимо;
- `10` — допустимо;
- `100` — допустимо;
- `-1` — ошибка;
- `101` — ошибка.

### Apply

- обычная скидка;
- скидка 0%;
- скидка 100%;
- отрицательная цена — ошибка;
- процент меньше 0 — ошибка;
- процент больше 100 — ошибка.

### FinalPrice

Проверить несколько товаров и убедиться, что итоговая сумма рассчитывается правильно.

Обязательно проверить:

- пустой список;
- несколько корректных товаров;
- товар с некорректной ценой;
- товар с некорректной скидкой.

## Команды

```bash
go test ./homework/...
go test -cover ./homework/discount
go test -race ./homework/...
```

## Критерии

- тесты запускаются командой `go test`;
- используются table-driven tests;
- используются `t.Run`;
- используются `assert`/`require`;
- проверены happy path, ошибки и границы;
- coverage ≥ 80%;
- тесты независимы и читаемы.
